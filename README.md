Project name // 
GENIUS :: Newage Bakery
Test-drive project created as part of the “GENIUS :: Fullstack Web Development”
course.
This project represents a modern bakery website with a fully responsive layout.
The main goal of this project was to practice frontend fundamentals and basic
Git/GitHub workflow.


Live Demo //
🔗 https://mwstranger.github.io/Genius-testdrive/


Features //
- Fully responsive design (mobile, tablet, desktop)
- Modern layout built with
- Flexbox
- Clean and semantic HTML structure
- Basic interactivity using vanilla JavaScript


Technologies Used //
- HTML5
- CSS3 / SCSS
- Flexbox
- JavaScript (vanilla)
- Git & GitHub
